🧠 2. What is Parallel Reduction?

👉 Normally (sequential):
You loop through an array one by one.

👉 In Parallel Reduction:

Work is divided among multiple threads
Each thread computes a partial result
All results are combined automatically
🔥 Example (Sum):

Instead of:

sum = a + b + c + d

Parallel:

Thread1 → a + b
Thread2 → c + d
Final → combine → total sum
⚙️ 3. What is OpenMP?

👉 OpenMP (Open Multi-Processing) is a library used in C/C++ for parallel programming.

You enable it using:

g++ filename.cpp -fopenmp -o output

⚡ 12. Important Viva Questions (VERY IMPORTANT)
❓ Q1: What is reduction in OpenMP?

👉 Reduction combines results from multiple threads into one variable.

❓ Q2: Why use reduction instead of normal variables?

👉 To avoid race conditions (multiple threads modifying same variable).

❓ Q3: What is race condition?

👉 When multiple threads access and modify same variable at same time → wrong output.

❓ Q4: What are reduction operators?

👉 Examples:

+ → sum
min → minimum
max → maximum
* → multiplication
❓ Q5: Why INT_MAX in min?

👉 To ensure any number in array will be smaller.

❓ Q6: Difference between sequential and parallel?
Sequential	Parallel

Simple	Efficient

👉 Special instruction starting with #pragma omp

🎯 13. Final Correct Average Function
void average_reduction(int arr[], int n) {
  int sum = 0;
  #pragma omp parallel for reduction(+: sum)
  for (int i = 0; i < n; i++) {
    sum += arr[i];
  }
  cout << "Average: " << (double)sum / n << endl;
}
